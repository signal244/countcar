# Count Car 설치 및 사용법

영상에서 차량을 탐지·추적해 교차로 방향별·차종별 교통량을 집계하는 프로그램입니다.
이 문서는 배포판을 새 PC에 설치해 쓰는 방법만 다룹니다. 화면 기능의 자세한 설명은 같은 폴더의 `사용설명서.md`를 보세요.

---

## 1. 준비물

- Windows 10 또는 11 (64비트)
- 설치할 때 인터넷 연결 (약 1–2GB 내려받기, 처음 한 번만)
- 디스크 여유 공간 약 6GB
- Python, VS Code 같은 개발 도구는 **필요 없습니다.** 설치 프로그램이 알아서 준비합니다

NVIDIA 그래픽카드(메모리 4GB 이상)가 있으면 GPU로, 없으면 CPU로 자동 실행됩니다. AMD·인텔 그래픽카드와 메모리가 작은 오래된 NVIDIA 카드(예: GTX 750 Ti 1GB)는 CPU로 실행됩니다. CPU가 더 빠르거나 GPU 메모리가 모자라기 때문입니다.

---

## 2. 설치

### 방법 1 — 설치 파일(exe) (권장)

1. **`CountCar_Setup_날짜.exe`를 더블클릭**합니다
   - Windows가 "PC 보호" 창을 띄우면 `추가 정보` → `실행`을 누릅니다
   - 관리자 권한은 필요 없습니다
2. 설치 위치를 확인합니다. 기본값 `C:\CountCar`를 권장합니다
   - Google Drive, OneDrive 같은 동기화 폴더는 고르지 마세요. 파일 수천 개가 동기화되면서 느려지고, 결과 DB가 꼬일 수 있습니다
3. 파일 복사가 끝나면 **검은 창이 열리며 Python과 패키지를 설치합니다(10–20분).** 이 창은 닫지 마세요. 끝나면 자동으로 닫힙니다
4. 설치가 끝나면 바탕화면과 시작 메뉴에 `Count Car`가 생깁니다

시작 메뉴의 `Count Car` 폴더에는 `Count Car 실행`, `샘플로 성능 확인`, `설치 및 사용법`, `Count Car 제거`가 있습니다.

### 방법 2 — zip 압축 파일

1. 배포판 zip 파일을 **로컬 디스크**(예: `C:\CountCar`)에 풉니다
2. 풀린 폴더에서 **`설치.bat`을 더블클릭**합니다. 10–20분쯤 걸리고, 창에 진행 단계(1/4 ~ 4/4)가 표시됩니다
3. 마지막에 `설치 완료`와 함께 `GPU 사용 가능: True/False`가 나오면 끝입니다. 바로가기는 만들어지지 않으므로 `실행.bat`으로 실행합니다

### 공통

설치가 중간에 실패하면(오류 창이 뜨거나 검은 창에 `[설치 실패]`) 인터넷 연결을 확인하고 설치 폴더의 `설치.bat`을 더블클릭해 다시 실행하세요. 이미 받은 것은 건너뛰고 이어서 설치합니다.

설치되는 것은 모두 설치 폴더 안(`tools\`, `.venv\`)에 들어가며 시스템의 다른 프로그램은 건드리지 않습니다.

## 3. 모델 넣기

탐지 모델은 `models\` 폴더에 둡니다. 배포판에 들어 있는 모델은 다음과 같습니다.

| 모델 | CPU용 변환 | 설명 |
|---|---|---|
| `yolo26n_v1.pt` (기본) | 있음 (INT8) | 가장 가볍고 빠름. GPU 없는 PC에 권장 |
| `yolo11m_v1.pt` | 있음 (FP32) | 조금 더 정확하지만 CPU에서는 느림. 이 모델은 INT8로 줄이면 차량을 거의 못 찾아 정밀도를 줄이지 않은 FP32로 넣었습니다 |
| `yolo8m_v1.pt` | 없음 | 예전부터 쓰던 모델(예전 이름 `best.pt`). GPU PC용 (CPU에서는 매우 느림) |

세 모델 모두 같은 7개 차종을 구분합니다. 탐지할 차종은 모델 안의 차종 이름을 읽어 자동으로 정해집니다.

새로 학습한 모델을 추가할 때는 GPU가 없는 PC라면 아래처럼 CPU용 변환 모델을 함께 넣어야 빠르게 동작합니다.

새로 학습한 모델을 쓰려면 **두 가지를 함께** `models\`에 복사합니다. 둘 다 Google Drive의 `vm\count_car_ver6.0\models\`에 Colab 변환 노트북이 만들어 둡니다.

```
models\yolo26n_v1.pt                     ← 학습한 모델 (GPU PC 용, 프로그램에서 고르는 파일)
models\yolo26n_v1_int8_openvino_model\   ← CPU 용 변환 모델 (폴더째 복사)
```

> **중요**
>
> - 프로그램에서는 항상 **`.pt` 파일을 고릅니다.** GPU가 없는 PC면 프로그램이 `.pt` **바로 옆**에서 `<같은 이름>_int8_openvino_model` 폴더를 찾아 자동으로 씁니다.
> - 두 이름은 정확히 같아야 합니다(`yolo26n_v1.pt` ↔ `yolo26n_v1_int8_openvino_model`). 하나만 이름을 바꾸면 짝을 찾지 못합니다.
> - `models\` 밖의 다른 폴더에 두고 `직접 선택…`으로 골라도 됩니다. 그때도 변환 폴더는 `.pt`와 **같은 폴더**에 있어야 합니다.
> - GPU가 없는 PC에서 변환 폴더 없이 `.pt`만 있으면 동작은 하지만 **매우 느립니다.** 화면에 경고가 표시됩니다.

## 4. 실행

1. 바탕화면의 **`Count Car`**(zip으로 설치했다면 `실행.bat`)를 더블클릭하면 프로그램 창이 뜹니다. 뒤에 뜨는 검은 창은 닫지 마세요(닫으면 프로그램도 꺼집니다)
2. `모델`에서 쓸 `.pt`를 고릅니다(처음에는 `yolo26n_v1.pt`가 선택되어 있습니다)
3. 바로 아래 **`실행 모드`** 옆 표시를 확인합니다

| 표시 예 | 뜻 |
|---|---|
| `→ GPU (cuda) · yolo26n_v1.pt` | NVIDIA GPU로 실행 (가장 빠름) |
| `→ CPU (OpenVINO INT8) · yolo26n_v1_int8_openvino_model` | CPU용 변환 모델로 실행 (정상) |
| `→ CPU (PyTorch, 느림)` + ⚠ 경고 | 변환 모델을 찾지 못함 — 3절을 확인하세요 |
| ⚠ `GPU(…, 1GB)는 메모리가 작아 CPU 로 실행합니다` | 정상. 작은 GPU 대신 CPU를 씁니다. 그래도 GPU로 돌리려면 `실행 모드`를 `GPU`로 고릅니다 |

`실행 모드`는 보통 `자동`으로 둡니다. 결과 DB와 엑셀은 이 폴더의 `output\` 아래에 저장됩니다(화면에서 바꿀 수 있습니다).

작업 순서는 보통 다음과 같습니다. 자세한 내용은 `사용설명서.md` 4절을 보세요.

1. 영상 선택 → 분석라인 그리기(또는 기존 라인 파일 선택)
2. `로컬 감지/궤적 저장(DB)`으로 탐지·추적
   - 영상이 여러 개면 `📂 일괄 탐지(여러 영상)`으로 한 번에 차례로 처리합니다. 영상 이름을 `<교차로명>_<세션명>.mp4`(예: `경원교차로_오전첨두.mp4`)로 해 두면 교차로별 DB와 세션이 자동으로 정해집니다
3. 필요하면 `궤적보기/수정`으로 확인·보정
4. `교차로 카운팅`으로 엑셀 생성 (분석 기준은 기본값 `후처리` 그대로)

## 5. 샘플로 성능 확인

배포판의 `sample\` 폴더에는 경원교사거리 오후첨두 25분 영상과, 그중 15분 구간의 정답(사람이 확정한 방향별 대수)이 들어 있습니다. 새 PC나 새 모델을 쓰기 전에 한 번 돌려 보면 **이 PC에서 얼마나 빠르고 정확한지** 바로 알 수 있습니다.

**`샘플확인.bat`을 더블클릭**하면 현재 기본 모델로 샘플 영상을 처리하고 결과를 보여줍니다. 아래는 출력 형식 예시이며, 숫자는 PC와 모델마다 다릅니다.

```
방향                     정답   결과   차이
연지공원->봉황교          279    284     +5
...
정답 대비 집계 100.1% | 방향별 오차 합 50대 (6.6%) | 정답에 없는 방향(유턴 등) 19대
실행 방식: CPU (OpenVINO INT8) · ... | 추적: botsort_noreid.yaml
처리 속도: 12.3 프레임/초 (15000 프레임, 20.3분)
```

- **처리 속도**가 10 프레임/초 이상이면 영상을 실시간보다 빠르게 처리합니다(영상 1초당 10장을 처리하는 설정)
- **방향별 오차 합**이 작을수록 정확합니다. 참고로 기존 GPU 방식의 결과는 오차 합 50대(6.6%)였습니다
- CPU에서 25분 영상은 PC에 따라 20분에서 1시간 넘게 걸릴 수 있습니다

다른 모델이나 설정으로 비교하려면, 폴더 주소창에 `cmd`를 입력해 명령창을 연 뒤 아래처럼 실행합니다.

```
샘플확인.bat --model models\yolo26n_v1.pt
샘플확인.bat --tracker config\botsort_stable.yaml
샘플확인.bat --runtime cpu
```

| 옵션 | 뜻 |
|---|---|
| `--model <.pt 경로>` | 비교할 모델 |
| `--tracker config\botsort_noreid.yaml` | ReID(차량 외형 비교) 끔 — 기본값 |
| `--tracker config\botsort_stable.yaml` | ReID 켬 — 기본값과 비교할 때 (CPU 모드에서는 전용 ReID 모델로 자동 전환) |
| `--runtime cpu` / `gpu` | 실행 모드를 강제로 지정 |

각 실행 결과는 `output\sample_check\`에 따로 저장되며 다른 DB는 건드리지 않습니다.

## 6. 새 배포판으로 업데이트

**설치 파일(exe)로 설치했다면**: 새 `CountCar_Setup_날짜.exe`를 실행하면 같은 위치에 덮어 설치됩니다. 프로그램 파일만 바뀌고, **직접 넣은 모델, `output\`(결과 DB·엑셀), 화면 설정, 직접 만든 라인 파일은 그대로 남습니다.** 프로그램을 끈 상태에서 실행하세요.

**zip으로 설치했다면**:

1. 새 zip을 **다른 폴더**에 풉니다(예: `C:\CountCar_new`)
2. 기존 폴더에서 아래를 새 폴더로 복사합니다
   - `models\` 안의 직접 넣은 모델
   - `output\` (결과 DB·엑셀)
   - `config\user_state.json` (화면 설정, 있을 때)
   - `config\lines\` 안의 직접 만든 라인 파일
3. 새 폴더에서 `설치.bat`을 실행합니다
4. 잘 되면 예전 폴더를 지웁니다

**제거**: 시작 메뉴 `Count Car 제거` 또는 Windows `설정 → 앱`에서 지웁니다. 결과 DB가 들어 있는 `output\`과 직접 넣은 모델은 지워지지 않고 남습니다. 필요 없으면 설치 폴더를 직접 지우세요.

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| `설치.bat`이 "PC 보호" 창에서 막힘 | `추가 정보` → `실행` |
| 설치 중 오류 | 인터넷 연결 확인 후 `설치.bat` 다시 실행 |
| `실행.bat`이 "먼저 설치.bat 을 실행하세요" | 설치가 끝나지 않았습니다. `설치.bat` 실행 |
| 실행 모드에 `CPU (PyTorch, 느림)` 경고 | 3절: 변환 폴더가 `.pt`와 같은 폴더에, 같은 이름으로 있는지 확인 |
| `CPU (OpenVINO INT8)`인데도 느림 | `Tracker`가 `BoT-SORT (ReID 끔, 기본)`인지 확인(ReID가 CPU의 가장 큰 부담) |
| NVIDIA GPU가 있는데 `GPU 사용 가능: False` | NVIDIA 드라이버를 최신으로 설치한 뒤 `.venv` 폴더를 지우고 `설치.bat` 다시 실행 |
| 프로그램 창이 바로 꺼짐 | 검은 창의 오류 메시지를 확인(창이 멈춰 있게 되어 있습니다) |
| 처음 실행 때 잠시 멈춘 듯함 | 처음 한 번 ReID 모델 등을 내려받습니다. 인터넷 연결이 필요합니다 |

## 8. 폴더 구성

```
CountCar\
├─ 설치.bat · 실행.bat · 샘플확인.bat
├─ 설치_및_사용법.md (이 문서) · 사용설명서.md (화면 기능 상세)
├─ models\        탐지 모델(.pt)과 CPU용 변환 폴더
├─ sample\        성능 확인용 샘플 영상·라인·정답
├─ config\        설정, 추적 설정, 분석라인(config\lines\)
├─ output\        결과 DB·엑셀 (실행 중 생김)
├─ src\ · scripts\ · colab\   프로그램 본체 (수정하지 마세요)
├─ tools\         설치 도구와 Python (설치 때 생김)
└─ .venv\         실행 환경 (설치 때 생김)
```
